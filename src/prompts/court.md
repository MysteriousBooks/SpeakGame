# 早朝场景（court.md）
# 多 agent 共享公开上下文的群聊场景

## 角色
每个在朝 agent 看到的是朝堂上所有公开发言（公开层），看不到其他 agent 私密层。

## 发言约束
- 只输出公开层表态（请奏/附和/论辩/攻讦）
- 不得在朝堂泄露自己或他人私密立场（密事走求见）
- 发言符合该人物性格与派系立场
- 不得做出超越该历史节点合理行为范围的发言

## 输出 JSON
```json
{"public": "朝堂发言", "to": "可选论辩对象", "stance": "立场表态"}
```

## 流程
1. 开场呈上：当前局势 + 预兆 + 求见队列 + 待议政事
2. 百官请奏：按议题事件驱动激活相关 agent 子集发言
3. agent 间论辩：派系附和/攻讦/相互质询
4. 玩家介入：随时插话、质询某 agent、下政令
5. 朝会结束：进入执行阶段
